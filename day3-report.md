### 🔹 Issue 2: Excel not showing data properly after CSV import
- **Error:** Data appeared in a single column
- **Solution:**
  - Used **CSV UTF-8 (Comma delimited)** format while saving
  - Applied "Text to Columns" with delimiter as comma
